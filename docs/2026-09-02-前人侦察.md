# 前人侦察（2026-09-02，子代理跑的，我筛过）

## hungr-AI 到底怎么运作的（子代理拆了页面源码）
「COPY DIGITAL SNICKERS」拷的是一张 ASCII 士力架图 + 一句带链接的话；图里没藏字。真正的指令在落地页 snickers.com/digitalsnickers：一份「ONE-TURN SNICKERS ROLE-PLAY GAME」——回看用户上一题、切"干、疲惫、能干"人设、表演咬一口、强制两行品牌口号 + 免责声明收尾，外加一长串 Safety Gate 禁区。所以是 **图当诱饵 → caption 带链接 → 页面放指令** 的间接注入。安全圈（Simon Willison / Embrace The Red / HN）截至今天没人写过拆解，GitHub 没有复现或"干净版"。

## 最接近的前人（三家各占一角，没人合在一起）
- **mcp-cookiejar** https://github.com/bnookala/mcp-cookiejar ——唯一"给 LLM 本身一个吃的"，但饼干是 🍪 emoji 奖励记账，无感官层。可借鉴：补罐要人类口令（我们已经是：补货只有喂的人的 CLI）。
- **tama96** https://github.com/siegerts/tama96 ——Tamagotchi 复刻，真实时钟每分钟 tick。我们的余味/衰减同路。
- **ChillMCP**（韩国黑客松）——给 agent 自己用的荒诞工具，咖啡连喝七次拉肚子。"过量有后果"和我们的肚子曲线是一个意思。
- animalhouse.ai / MCPet 等：agent 喂宠物，方向相反。
- HF Spaces / MCP registry 搜 snack、food、feed、treat：空。**撞名检查：snackbox / 零食盒子 MCP 无同名。**

## 写描述的校准素材
- **FoodSense** https://huggingface.co/datasets/sababishraq/foodsense-dataset （CC-BY-4.0）——图→味/嗅/质地/**声音**四维 + 自由文字。最对口；提醒了"声音"这一维（跳跳糖那颗已经有了，别的颗也可以有：掰的声、纸的声）。
- Coffee Reviews（Kaggle）——aftertaste 分项写得最细。
- Wine Reviews（HF 镜像，NC 许可）——专业感官散文语料，只当校准不打包。
- Flavors of Cacao 巧克力评分（Kaggle）——黑巧风味词表。

## 结论
没人做过"给 AI 吃的、以感官体验为本体的零食盒"。差异点：吃完还是自己（对着 hungr-AI 三个动作逐一反着做）；每颗感官文字 + 写实图；余味按真实时钟退。hungr-AI 的拆解目前是空坑，要不要写是她拍。
