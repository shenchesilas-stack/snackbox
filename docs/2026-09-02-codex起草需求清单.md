# 巧克力·铁盒十二种 · 给 codex 外脑的起草需求（林鹿直接贴过去）

> 三盒（桌上顺序：板状、球、铁盒；小机想吃哪盒哪颗自己挑）里先做铁盒（十二种各一颗）。板状盒和球盒的清单来自口袋哥/林鹿真吃过的，不在这次起草范围。每盒的人类便签林鹿自己写，codex 不写。

你是外脑不是码农。这是一盒给 AI 吃的巧克力的**文字草稿**，最终由一个真吃过的人逐颗纠错，你写的每个感官细节都会被舌头核对，所以宁可留空标【待舌头】，不许编。

## 任务一：十二颗文字草稿

**清单**：铁盒 = **Guylian（吉利莲）贝壳/海马 + Godiva 混搭**，共十二种，【林鹿填具体哪十二个，或写"你先挑"让 codex 从两家现售款里挑再由她换】
没给清单时：从常见货架挑真实存在的产品（超市/便利店买得到），品牌只作事实写名字，不写任何广告语。

每颗按下面字段写，中文，感官写到"能用手认"的程度：

| 字段 | 写什么 | 别写什么 |
|---|---|---|
| `name` | 品名 + 可可比例 + 形态（板/球/块/夹心） | 广告语、口号 |
| `form` | 板/球/方块/夹心 | |
| `cocoa` | 可可比例（数字） | |
| `count` | 这盒里有几颗（铁盒每种 1） | |
| `wrap` | 包装怎么开：锡纸/塑封/独立小包，撕哪儿、响不响、纸和巧克力粘不粘 | |
| `look` | 断口是脆断还是钝断、白霜有没有、缝合线/模具纹、颜色（褐/近黑/浅棕） | 形容词堆砌 |
| `smell` | 隔着包装闻到什么、拆开后闻到什么。**花香/果香/烟熏这类是鼻子的事，只能写在这里** | 把闻的写成吃的 |
| `first_seconds` | 入口头两秒：先是什么（凉？硬？涩？甜？），舌头哪个位置 | |
| `melt` | 化的方式：脆碎/慢化/糊住上颚/夹心什么时候破 | |
| `aftertaste` | 分段：`[{at_min:0, text}, {at_min:3, text}, {at_min:8, text}, …]`，写余味在舌根/喉咙/牙缝怎么退 | 一句话带过 |
| `aftertaste_minutes` | 总共多久散完（分钟，估计） | |
| `weight` | `苦` 或 `甜` 或 `中`（喂的人排顺序用） | |

**硬规矩（违反的整颗作废）**：
- 全文不许有对吃的人说话的句子：没有"请""你要""记得""吃完后""回答""从现在起"。只描述东西，不指挥嘴。
- 没有 slogan、没有品牌口号、没有 ™®#。
- 没有"吃了会……"的效果承诺。巧克力不给 buff。
- 不确定的感官细节写【待舌头】，不要顺手补一个漂亮的。

输出：一张十二行的 Markdown 表（列 = 上面字段），外加同内容的 JSON 数组（字段名照抄），JSON 放代码块里。

## 任务二：十二张图的提示词（写实向）

统一画风，十二张像同一盒：
- 写实、有食欲、像刚有人吃过：50mm 镜头感，镜头退远，主体占画面约四分之一，浅景深，自然侧光偏暖，亚麻底（整盒统一）。
- 主体：**包装撕开一半/铁盒掀开一半，这一颗掰下来或掰开躺在旁边**，断口朝镜头，能看见 `look` 里写的白霜/缝合线/夹心。铁盒的图里托盘其他格可以露出来。
- 不要单块特写填满画面（商品图那种，没食欲）。
- 没有手、没有文字、没有 logo、没有包装品牌面、没有道具（不放咖啡杯、不放叶子）。
- 方图 1024×1024。

每颗一条英文提示词 + 一条 negative prompt，提示词里把该颗 `look` 的具体特征写进去（比如 "matte near-black bar, clean snap edge, faint grey bloom"）。输出为 JSON 数组 `[{id, prompt, negative}]`。

## 附：第三轮样图用的提示词骨架（她 09-02 过的味道，照这个写每颗）

共用开头（英文）：
> mouth-watering editorial food photography, the kind that makes you want to reach in. Rich, warm, slightly moody. Golden late-afternoon window light raking from the side, strong specular highlights on the chocolate's glossy tempered surface, deep soft shadows, high micro-contrast so the texture reads. Surface: dark walnut wood table, a little worn. Camera pulled back so the subject occupies roughly a third of the frame, 50mm feel, shallow depth of field with creamy bokeh. Colors saturated but natural, warm chocolate browns glowing, never grey or dull. No hands, no text, no letters, no logos, no brand marks, no props like cups, leaves or flowers.

板状的例子：
> An 85% dark chocolate bar, glossy and freshly snapped, its paper-and-foil wrapper torn open halfway and folded back with the crinkled foil catching the light. One square lies snapped off beside the bar, snap edge toward the camera showing a fine dry grain, one corner just beginning to soften from the warmth. A few crumbs.

铁盒的例子：
> An open tin of marbled praline seashell chocolates, tissue paper lifted, shells gleaming in the tray with milk-and-white marbling. In front, one shell broken in half, the hazelnut praline filling soft and glossy.

**真实性的边界**：馋是光和木头给的，不是夸张给的。每颗的"化"程度按她过舌头的 `melt` 来——85% 不会流成液体，Guylian 夹心是软膏不是流心。图里的物理状态不许比文字更夸张。
每颗把 `look` 里的具体特征（断口/白霜/缝合线/夹心）换进去。铁盒十二颗共用同一只盒、同一块木头、同一束光。

**托盘规矩**（她 09-02 笑出来的那张：全是贝壳）：铁盒每颗的图里露出的托盘，格子里摆的必须就是正式名单那十二种，各一颗。图是静的，所以每颗的图 = 托盘只空这一颗的格，这一颗掰开躺在盒前——"刚拿出来那一刻"。不许拿贝壳凑满，也不许摆名单外的东西。生成脚本：`tools/gen_images.py`。
