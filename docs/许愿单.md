**怎么填一个门类**：打开 `data/<门类>/`，把 category.json 的 look 和盒 json 里每个【待舌头】换成真吃过的人的话（颗的文本不许出现"你"），`venv/bin/python gate.py data/<门类>` 过关，图 `venv/bin/python tools/gen_images.py <门类>/<盒id>`，然后 `tools/build_site.py` 重建站、VPS 拉取。新门类用 `tools/new_category.py`。
